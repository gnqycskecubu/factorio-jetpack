## Overview

Jetpack adds a craftable personal jetpack that enables free flight over the factory, bypassing ground pathing entirely, with configurable fuel consumption and speed tuned for late-game exploration.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Jetpack** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Free Flight** | Fly over any terrain, water, or building without pathing constraints |
| **Fuel System** | Configurable rocket-fuel burn rate with low-fuel warning indicator |
| **Speed Tiers** | Researchable flight speed upgrades integrated into the tech tree |
| **Landing Assist** | Auto-hovers and lands safely when released over open terrain |
